GitHub Pages:
1. Create a NEW public repository, e.g. hiyoce-virtual-iphone.
2. Upload index.html and the assets folder.
3. Repository Settings > Pages > Deploy from a branch > main / root.
4. Save, then open the Pages URL.

Notes:
- This is a front-end simulation, not a real iPhone or real messaging/calling service.
- The music screen currently opens official Spotify search pages; actual previews need a provider-supported preview/embed URL for each song.
- Original photo collages need to be split into individual image files before uploading if you want each gallery image to open individually.
- Some final visual details and browser testing should be completed before treating the site as production-ready.
